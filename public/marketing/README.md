# Piezas publicitarias de Suya

Archivos generados con la herramienta de imágenes integrada y revisados visualmente antes de
publicarlos en el repositorio. Los flyers se generan completos desde el prompt; no se editan
fotografías después. Cada pieza reserva un espacio limpio para colocar el logo oficial de Suya
sin recrearlo con IA.

## Sistema visual reutilizable

- Escenario: Sullana, Piura; Puente Viejo, río Chira e Iglesia Matriz cuando el formato lo permite.
- Paleta de interfaz y campaña: carbón `#182F2F`, rojo tomate `#CB0A16`, lima `#8CCA39`, marfil
  `#FFF9EF` y amarillo sol `#FFC107`.
- Composición: jerarquía editorial, área de lectura despejada, fotografía cálida de comida local,
  textura de papel discreta y un solo CTA.
- Marca: el logo oficial se conserva intacto; el modelo deja un panel vacío cuando no puede
  reproducirlo fielmente.
- Texto: solo mensajes de Suya y categorías genéricas; no se incluyen nombres ni logos de marcas
  de terceros en piezas publicitarias.
