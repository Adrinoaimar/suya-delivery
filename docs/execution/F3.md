# Checkpoint F3 — separación multiapp

## Resultado

- Entradas físicas independientes para cliente, repartidor y backoffice.
- Shell común sin importar el router legado ni contaminar otros bundles.
- Bootstrap de pedidos fuera de backoffice.
- Rutas y layout propios; ayuda del repartidor ya no termina en 404.
- Enlaces entre aplicaciones configurables por variables para migrar de `pages.dev` al dominio final.
- Service worker y manifest limitados a cliente.
- Verificador automático rechaza páginas/chunks y activos PWA cruzados.

## Evidencia

- `npm run build:apps`: tres builds y aislamiento pasan.
- Typecheck, lint y 49 pruebas: pasan.
- Revisión Kimi K3 xhigh: contaminación PWA y enlaces customer→rider corregidos; supuesto 404 de
  Pages descartado contra documentación oficial.
- Claude: timeout sin salida; continuidad asumida localmente.

## Gate

Backoffice todavía no se publica: Auth real y guard por rol pertenecen al siguiente checkpoint.
