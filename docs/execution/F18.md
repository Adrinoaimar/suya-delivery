## Configuración GA4

Copiar `.env.example` y completar únicamente en el proveedor de despliegue:

```text
VITE_ANALYTICS_PROVIDER=ga4
VITE_GA4_MEASUREMENT_ID=G-XXXXXXXXXX
```

La aplicación no inyecta el script mientras la persona no acepte analítica. El rechazo se guarda
localmente y los eventos no incluyen nombre, correo, teléfono, dirección ni contenido libre. Para
desactivar la medición basta dejar el proveedor en `none` o retirar el ID y volver a desplegar.
