# F29 — Toolchain Android, regresión nativa y APK 1.5

Fecha: 2026-09-16 (`America/Lima`)

## Objetivo

Desbloquear la verificación Android local, corregir la regresión de notificaciones multilínea y producir APK debug actualizables desde el código vigente sin declarar una entrega productiva.

## Cambios

- Se verificó Temurin JDK 21.0.12.1 por SHA-256 y se instaló un SDK Android temporal oficial con API 36 y Build Tools 35/36.
- `YapeNotificationListenerService` separa la extracción Android de la normalización JVM; `EXTRA_TEXT_LINES` queda cubierto sin depender de métodos Android no simulados.
- Android avanza de `1.4/5` a `1.5/6`, evitando reutilizar el código de versión de artefactos distribuidos anteriormente.
- Se preservó una copia local de las APK `1.4/5` en `output/android-1.4-code5-20260916/` antes de reconstruir.

## Evidencia

- `android/gradlew test`: `BUILD SUCCESSFUL`; `:app:testDebugUnitTest` ejecuta 13/13.
- Suite Vitest: **73 archivos / 363 pruebas**.
- `npm run typecheck`, `npm run lint`, `npm run security:secrets` (**946 archivos**) y `git diff --check`: pasan.
- `npm run build:mobile:roles`: compila bundles aislados Rider, Backoffice y Wallet Observer y ejecuta `assembleDebug` correctamente.
- Las tres APK pasan `unzip -tqq`, `aapt dump badging` y `apksigner verify`; SDK mínimo 24, objetivo 36, un firmante y esquema v2.
