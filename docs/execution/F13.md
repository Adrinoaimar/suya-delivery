# F13 — Google Auth, motion y cartas verificables

Fecha: 6 de septiembre de 2026 (`America/Lima`)

## Resultado

- El alta de clientes separa ingreso y creación, confirma contraseña, valida por campo y anuncia
  carga, error y éxito de forma accesible.
- Google OAuth usa Supabase Auth con PKCE. Web conserva una ruta local segura; Android/iOS abren el
  proveedor con `@capacitor/browser` y regresan por `com.suya.app://auth/callback`.
- Google aparece solo en cliente. Repartidor y backoffice conservan acceso controlado por roles.
- Motion usa duraciones de 140/220/320 ms, drawer lateral correcto y respeta la preferencia manual o
  del sistema para reducir movimiento.
- Donde Joel queda preparado como catálogo informativo: 133 productos de precio inequívoco, cuatro
  cartas originales, menú público y pedidos desactivados hasta confirmar datos operativos.
- La nueva carta de Andá Paya se añadió a su galería con advertencia visible, hash y procedencia,
  sin sobrescribir los 58 productos activos porque varios precios entran en conflicto.
- Las cartas se muestran completas con `object-contain` y visor ampliado; no se recortan como fotos.

## Pruebas

- `npm run typecheck`: pasa.
- `npm run lint`: pasa con 8 warnings heredados en `apps/menu/app.js`.
- `npm test -- --reporter=dot`: 23 archivos, 109 pruebas pasan.
- `npm run build:apps`: customer, rider y backoffice compilan.
- `npm run verify:production`: 327 archivos; sin simulaciones ni secretos.
- `npm run security:secrets`: 439 archivos; sin patrones de secreto.
- `npm run test:e2e`: 9 combinaciones de app/viewport pasan.
- `npm run build:mobile`: bundle unificado y sincronización de 10 plugins pasan.
- `:app:testDebugUnitTest` y `:app:assembleDebug`: pasan con JDK 25 y target Java 21.
- APK debug: 12,088,022 bytes; firma v2 válida; SHA-256
  `0EE749AAC4370182ADAB8976644E1265E4731C2410A848FB0DA204E479ED0E2B`.
- Manifest del APK contiene `VIEW`, `BROWSABLE`, esquema `com.suya.app`, host `auth` y ruta
  `/callback`.
- Smoke visual local: registro muestra cuatro campos y validación vacía presenta mensajes por campo.
  El control Google consulta configuración pública y aparece deshabilitado mientras el proveedor
  remoto esté apagado.
- Migración Donde Joel: validación estática confirma 133 fuentes, IDs y órdenes únicas. CI aplicó
  la migración y aprobó 18 aserciones pgTAP, incluido rechazo real de pedidos y galería Andá Paya
  idempotente.

## Gates externos

- El proveedor Google está desactivado en Supabase. Falta crear credencial OAuth web en Google
  Cloud, cargar Client ID/Secret en Supabase y permitir el callback móvil. Ningún secreto se guarda
  en frontend ni repositorio.
- La migración de Donde Joel no se aplicó a producción. Docker/Podman no está instalado localmente;
  la validación real de base se ejecutó en CI antes de cualquier despliegue.
- Debe confirmarse si “Donde Joel Cevichería” y “Donde Joel Fast Food” son una misma sede, además de
  dirección, coordenadas, horario, envío, mínimo, ETA y opciones obligatorias.
- La carta nueva de Andá Paya requiere conciliación comercial antes de cambiar catálogo o teléfono.
- APK sigue siendo debug. Distribución requiere firma de release y prueba física.
