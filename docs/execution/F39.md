## Resultado

- La portada cliente ahora presenta «¿Quieres descargar Suya?» en móvil y escritorio. Lleva a
  `/descargar`, que muestra disponibilidad de Android e iOS. Header y footer también enlazan esa ruta.
- Commit publicado en `main`: `dd85133` (`feat(web): add app download callout`).
- Cloudflare Pages workflow [36281009074](https://github.com/Adrinoaimar/suya-delivery/actions/runs/36281009074)

  `https://suyadelivery.com/descargar` la página publicada.

## Verificación

- Pasaron `npm run typecheck`, `npm run lint`, `npm test` (77 archivos, 399 pruebas), `npm run build`
  y `npm run security:secrets`.
- El preflight productivo local no pudo validarse porque este entorno no tiene variables protegidas
  de producción. El workflow de GitHub usó el environment configurado y pasó sus gates.
- `npm run verify:production` ejecutado sobre el build genérico local falló por usar configuración
  ausente y bundles mock. No es el artefacto de release; `build:apps` y `verify:production` pasaron en CI.
