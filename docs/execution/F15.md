# F15 — Cuentas de restaurantes y invitación segura

Fecha: 9 de septiembre de 2026 (`America/Lima`)

## Resultado

- Backoffice reemplaza placeholder `/restaurants` por gestión de `restaurant_account_registry`.
- Solo `platform_admin` ve la sección; personal de restaurante no recibe acceso a datos de otros negocios.
- Se pueden guardar representante, correo y notas. Correo válido mueve casillero a `ready_to_invite`.
- Nueva Edge Function `invite-restaurant-owner` valida JWT y `app_metadata.role`, envía invitación
  con `auth/v1/admin/invite`, luego verifica correo confirmado, vincula propietario y activa cuenta;
  `SUPABASE_SERVICE_ROLE_KEY` vive únicamente en runtime y nunca se devuelve.
- Workflow manual `Desplegar Edge Functions Supabase` preparado; no se ejecuta automáticamente.
