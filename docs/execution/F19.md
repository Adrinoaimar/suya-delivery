# F19 — Código de entrega persistente en Cliente

Fecha: 2026-09-19 (America/Lima)

## Objetivo

Mantener visible código de entrega desde Cliente durante todo ciclo pedido. Corregir texto GPS cuando pedido ya está en camino.

## Cambios

- `OrderDetailPage` renderiza `OrderCodes` también para pedidos entregados o cancelados.
- `GuestOrderPage` conserva código en pedidos a domicilio cerrados; QR de mesa sigue sin código de entrega.
- `OrderCodes` reutiliza mensaje informativo para pedidos cerrados.
- Texto GPS usa `riderTrackingMessage` según `preparing`, `picked_up` u `on_the_way`.
- Regresión añadida para código persistente y mensajes GPS.
