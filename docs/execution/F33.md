# F33 — cierre de imágenes SEO

Fecha: 2026-09-21 (`America/Lima`)

## Objetivo y resultado

Completar la auditoría de imágenes sin cambiar el diseño. Los 16 elementos `<img>` de React tienen
alt correcto o vacío decorativo, dimensiones, estrategia de carga y decodificación. Las portadas
críticas usan prioridad alta; miniaturas y fallbacks usan carga diferida. Los PNG productivos grandes
se resuelven a WebP y los artes de marketing no están referenciados por la web.

## Evidencia

- Auditor estático: 16 imágenes, 0 hallazgos.
- Typecheck y lint: pasan.
- Suite base anterior al ajuste: 76 archivos / 387 pruebas y CI del PR #49 en verde. Las seis suites
  afectadas por imágenes pasan con 42 pruebas, incluida la nueva regresión global de `<img>`.
- Build cliente y verificador de bundles: pasan.
- Lighthouse móvil local repetido: 74 rendimiento, 100 accesibilidad, 96 buenas prácticas y 100 SEO;
  LCP 3.1 s y CLS 0. La variación observada frente a la pasada anterior fue 74–76.
