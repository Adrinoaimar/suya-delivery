# F27.7 · Persistencia reintentable del webhook

`a35faa6` corrige un borde de conciliación: `culqi-webhook` ya no responde éxito si falla el `PATCH` de `payment_attempts`. Devuelve `502`, registra el error y permite que Culqi reintente la notificación. Cada transición también actualiza `updated_at`; una autorización limpia un `failure_code` residual.

La actualización conserva el filtro `status=eq.pending`, por lo que un webhook repetido no reescribe un intento ya cerrado. El webhook sigue validando nuevamente en Culqi el identificador, monto y moneda antes de cambiar el estado.
