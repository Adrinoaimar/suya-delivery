# F32 — SEO local para delivery en Sullana

Fecha: 2026-09-21 (`America/Lima`)

## Objetivo

Preparar `suyadelivery.com` para competir por búsquedas locales como «delivery Sullana», sin afirmar
posiciones garantizadas ni inventar señales comerciales.

## Resultado

- Doce documentos públicos entregan HTML inicial indexable, canonical, descripción, `h1` y JSON-LD.
- Home amplía contenido local; footer y páginas de confianza enlazan Sobre Suya, Contacto, Ayuda,
  Privacidad y Términos.
- Sitemap, robots, `llms.txt`, release smoke y verificador de bundles cubren los activos SEO.
- La intro web dejó de bloquear el contenido; fuentes locales precargadas y contraste AA corregido.
- Lighthouse móvil local: 76 rendimiento, 100 accesibilidad, 96 buenas prácticas y 100 SEO; FCP 2.7 s,
  LCP 3.0 s, TBT 560 ms y CLS 0.

## Pruebas

- `npm run typecheck`
- `npm run lint`
- `npm run security:secrets` — 797 archivos, sin patrones de secreto
- `npm test` — 76 archivos, 387 pruebas
- `npm run build:apps` — customer, rider y backoffice
- `npm run verify:production` — 697 archivos, sin simulaciones ni secretos
- `git diff --check`
- Smoke visual Playwright móvil/escritorio y Lighthouse móvil local

## Límites y pendientes

El build se validó con configuración pública sintética; no prueba el backend productivo. Antes de
declarar producción lista faltan publicación protegida, smoke de las doce URL, tipos MIME y
Lighthouse real. La posición 1 depende además de indexación, Search Console, ficha de empresa legítima,
reseñas auténticas, citaciones y enlaces locales. No se usaron datos comerciales no verificados.
