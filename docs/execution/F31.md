# Checkpoint F31 — medidor propio de visitas

## Resultado

Se activó analítica first-party y privacy-safe para Customer web. Las visualizaciones de página y
clics en enlaces se registran como contadores agregados diarios incluso sin consentimiento, sin IP,
cookies, identificadores, consultas, referrers ni contenido del pedido. Las visitas únicas siguen
siendo opt-in: cada navegador genera un UUID local después de aceptar y Supabase guarda solo un
digest SHA-256 con alcance de fecha local `America/Lima`.

La migración `20260920170000_first_party_analytics.sql` está versionada y cubierta por CI. La
auditoría live confirmó que el bundle público contiene el aviso, el estado de consentimiento y la
RPC de registro; no se pudo consultar la migración remota desde este entorno por falta de acceso
Supabase. La consulta agregada queda restringida a `platform_admin`.

Customer web muestra el aviso «Preferencias de analítica» con «Solo necesaria» y «Aceptar analítica».
El panel de operaciones muestra visitantes consentidos, visualizaciones y clics agregados únicamente
a plataforma, sin exponer hashes.
