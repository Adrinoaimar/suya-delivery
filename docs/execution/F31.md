# Checkpoint F31 — medidor propio de visitas

## Resultado

Se activó analítica first-party, anónima y opt-in para Customer web. Cada navegador genera un UUID
local después de aceptar el consentimiento; Supabase guarda un digest SHA-256 con alcance de fecha
local `America/Lima`, sin IP, nombre, correo, ruta, campaña ni pedido. La métrica representa
visitantes únicos diarios y puede ser aproximada ante abuso deliberado.

La migración `20260920170000_first_party_analytics.sql` quedó aplicada y registrada en Supabase
producción. La consulta transaccional confirmó `first_visit: true`, `duplicate_visit: false` y
rollback; no quedaron filas de prueba. La consulta agregada queda restringida a `platform_admin`.

Customer web muestra el aviso «Preferencias de analítica» con «Solo necesaria» y «Aceptar analítica».
El panel de operaciones muestra agregados únicamente a plataforma, sin exponer hashes.
