# F11 — Aplicación móvil Suya

Fecha: 6 de septiembre de 2026 (`America/Lima`)

## Resultado

- Capacitor 8 integra el build customer existente en Android e iOS con `com.suya.app`.
- Delivery, Suya Menús y rutas QR conservan React, Zustand, Supabase y RLS del producto web.
- GPS nativo solicita permiso al usarlo; checkout y seguimiento comparten el contrato de ubicación.
- Icono y splash Suya reemplazan los recursos genéricos en ambas plataformas.
- APK debug instalable generado. iOS queda preparado para build de simulador en macOS CI.

## Pruebas

- `npm run typecheck`: pasa.
- `npm run lint`: pasa con 8 warnings heredados en `apps/menu/app.js`.
- `npm test -- --reporter=dot`: 18 archivos, 92 pruebas pasan.
- `npm run security:secrets`: 421 archivos, sin patrones de secreto.
- `npm audit --omit=dev --audit-level=high`: 0 vulnerabilidades productivas.
- `npm run build:apps && npm run verify:production`: 475 archivos, sin mocks ni secretos.
- `gradlew assembleDebug --no-daemon`: 366 tareas, build exitoso.
- `apksigner verify --verbose`: firma APK v2 válida.
- APK: 11,364,209 bytes; SHA-256 `F0FAE57623593F4ADDAF4C92C9648F3F0BF9E2103C5FBCDD288D2AE00D92DFC2`.
- `git diff --check`: pasa.

## Fallos reales y gates externos

- `verify:production` falló primero por un `dist/` heredado; el build limpio de las tres apps lo corrigió.
- No había Android conectado: instalación y smoke físico pendientes.
- Windows no compila ni firma iOS. `.ipa` requiere cuenta, certificado y perfil Apple; release Android
  requiere keystore de distribución. Push notifications requieren FCM/APNs.
