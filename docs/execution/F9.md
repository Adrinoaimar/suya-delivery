# Checkpoint F9 — Cierre de builds simulados

## Resultado

- `scripts/build-apps.mjs` ahora rechaza cualquier build multiapp sin Supabase, proveedor OSM,
  URL/ref coincidentes y clave pública válida.
- `scripts/verify-app-bundles.mjs` rechaza explícitamente chunks `MockOrderService`,
  `MockStoreService` y `MockPaymentService` en cada aplicación.
- El workflow heredado de GitHub Pages dejó de publicar artefactos; la publicación real queda
  exclusivamente en Cloudflare Pages con secretos y entorno protegido.

## Evidencia local

- Sin variables productivas: `npm run build:apps` falla cerrado con `Build productivo rechazado`.
- Con configuración pública sintética de prueba: tres builds pasan y `verify:production` valida
  352 archivos sin simulaciones ni secretos. Esa configuración no se usa para publicar.
- Smoke Chrome real anterior: seis casos, móvil y escritorio, HTTP 200; rutas protegidas en `/login`.
