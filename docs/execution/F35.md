# F35 — Preparación de firma y distribución Android

Fecha: 2026-09-23 (`America/Lima`)

## Objetivo y corrección

Preparar la actualización de Cliente, Rider, Backoffice y Wallet Observer sin presentar APKs
debug o unsigned como releases. `docs/setup/android-release-signing.md` documentaba variables de
firma que `android/app/build.gradle` no utilizaba. Gradle ahora conecta esas cuatro variables,
rechaza configuración parcial e informa cuáles faltan; sin ellas conserva el build unsigned.

## Evidencia

- `npm run typecheck`: PASS.
- `npm run lint`: PASS.
- `npm run security:secrets`: PASS; 823 archivos Git revisados.
- `npm test`: PASS; 85 archivos, 411 pruebas (incluidas dos pruebas estáticas de la configuración
  de firma; no equivalen a compilar Gradle).
- `npm run build`: PASS con proyecto, clave pública y URLs sintéticas; genera customer, rider y
  backoffice, y `verify:production` acepta 700 archivos sin mocks ni secretos. No es staging real.
- Inspección local del bloque de firma APK v2: las cuatro APK release code 7 comparten un mismo
  certificado, distinto al de una APK debug disponible. Esta inspección no sustituye la
  comprobación oficial con `apksigner` ni una prueba de actualización.
- Java, `adb` y `apksigner`: no disponibles en el host; Gradle release y Android QA: BLOCKED.

## Bloqueos para distribuir

1. Recuperar la **clave de firma original** y entregarla al runner mediante un gestor seguro, no
   al chat ni al repositorio. Confirmar digest SHA-256 con `apksigner` para APK vieja y nueva.
2. Configurar Supabase/URLs de staging aislado para compilar y probar sin producción.
3. Ejecutar Android CI y pruebas de login, instalación/actualización code 7→8 y regresión por
   rol sobre el mismo commit. No sustituir esto con un build web sintético.
4. Tras aprobar QA, compilar los cuatro roles con backend autorizado, firmar, verificar paquetes,
   versión y certificados, y solo entonces empaquetar las APK para distribución.

Estado: **NO APTO PARA DISTRIBUCIÓN**. No se generó ni envió una APK nueva; no hubo despliegue.
