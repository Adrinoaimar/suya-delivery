# F27.6 · Preflight de pagos

El script `npm run verify:payments` valida, sin cargos ni migraciones, la configuración mínima de producción para Supabase, mapas y orígenes canónicos. Culqi es opcional: el modo manual directo usa `VITE_CULQI_GATEWAY_ENABLED=false` sin llave pública; el modo Culqi usa `true` y exige `pk_test_...`/`pk_live_...`.

## Uso

Para revisar variables públicas sin red:

```bash
npm run verify:payments
```

Para un entorno listo para desplegar, añadir `--deployment`; exige además los nombres de secretos usados por las Edge Functions. Con `--network`, ejecuta únicamente `OPTIONS` contra `create-culqi-order`, `charge-culqi-card` y `culqi-webhook`.

El gate rechaza project refs distintos, claves `sk_` en el frontend, un flag de Culqi ausente/ambiguo, una llave inválida cuando se entrega, mapas `mock`/ausentes, comodines u orígenes incompletos. Nunca ejecuta cargos, aplica migraciones ni publica cambios.
