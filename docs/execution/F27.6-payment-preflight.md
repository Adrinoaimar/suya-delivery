# F27.6 · Preflight de pagos

El script `npm run verify:payments` valida, sin cargos ni migraciones, la configuración mínima de producción para Supabase, Culqi, mapas y orígenes canónicos.

## Uso

Para revisar variables públicas sin red:

```bash
npm run verify:payments
```

Para un entorno listo para desplegar, añadir `--deployment`; exige además los nombres de secretos usados por las Edge Functions. Con `--network`, ejecuta únicamente `OPTIONS` contra `create-culqi-order`, `charge-culqi-card` y `culqi-webhook`.

El gate rechaza project refs distintos, claves `sk_` en el frontend, Culqi deshabilitado, mapas `mock`/ausentes, comodines u orígenes incompletos. Nunca ejecuta cargos, aplica migraciones ni publica cambios.
